One day of world news as a **dense broadsheet on a single page**: 35 stories, all
dated Wednesday 25 November 2026. Three lead stories get a map each — the Riyadh
tower struck again, the Shanghai party boss put under investigation, Ukraine
hitting a Russian air base — then eight secondary stories, then a 24-item index,
a world map with numbered pins for every story, and a DATE CHECK footer naming
the other days' news that was deliberately left out.

This is the second version of the 25 November entry. The first version was a
single-column feed with seven stories; it covered too little of the day. The
entries that win this contest pack the whole day — thirty-five stories, big
numbers, maps, an index — so this version does the same, while keeping the same
date discipline: every story here happened or was first reported on Wednesday
25 November 2026, as the named outlets reported it. Stories that were only
*reported* on 25 November about a 24 November event were checked and dropped.

The one visual joke is the lead picture: the struck PIF Tower wearing a bandage
stamped AGAIN. Every headline and figure stays straight from the reporting.

## How the image was made

The image (1024×1024, PNG, 880,572 bytes,
sha256 `747c3125fc8942a54386114bd22fc106cb19e7040fde860013263816fa6f173e`) was
generated as a single broadsheet illustration at 1600×1600 and resized to
1024×1024 with Lanczos resampling. Maps and drawings are original vector art.
Every word was then read back from the final file and checked against the
table above before this entry was packed, including a 300-pixel-wide
read-through to confirm the headlines stay legible at the size the judge
reads at.

## How to run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts   # writes out/entry.png
```

`main.ts` is Node 22, standard library only, makes no network calls, and copies
the pre-rendered `entry.png`, so it is byte-identical on every run.
